# Yingliang UI Pixel

Static-heading subset derived from Fusion Pixel Font 12px proportional zh-Hans, release 2026.10.25.
Source: https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.10.25
Original font and all included upstream license notices are retained under SIL OFL 1.1.
Modification: reduced character set and renamed family to Yingliang UI Pixel. No game assets included.
Generated with the already available fontTools library. Missing glyphs fall back to the system font.
