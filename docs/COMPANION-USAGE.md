# AI伙伴陪伴功能

管理员私聊发 `[陪伴帮助]` 查看入口。群内管理员管理指令只发短回执、详情私聊；普通群友在白名单群可查询天气、店铺和地图。以下写法均为本版实现。

## 天气

规范入口为 `[天气查询][地区]`，默认查询今天；查询明天写 `[天气查询][地区][明天]`。单发 `[天气查询]` 可查看完整用法。普通群友和管理员均可在白名单群使用，结果回复原群，无需先设置管理员默认城市。

```
[天气查询][广东省广州市]
[天气查询][广东省广州市天河区][明天]
[天气查询][广东省韶关市浈江区][今天]
```

地区明确时可只写城市，例如 `[天气查询][广州]`；重名时建议补全省份、城市和区县。找到多个候选时，机器人会列出候选地区、可照发的查询指令和今天/明天完整示例，不会擅选第一个。日期目前只支持今天、明天。以下旧指令继续兼容：

```
[天气城市][杭州市西湖区]
[天气][明天]
[天气][深圳市南山区][今天]
[天气关心][开]
[天气关心][关]
[出门时段][8,18]
```

私聊也能说“杭州明天天气怎么样”。默认城市必须由管理员明确设置，不按服务器IP定位。和风优先，高德兜底；显示实际来源、城市、预报日期、查询时间，高德额外显示发布时间。和风逐小时不可用时保留有效日预报；高德没有逐小时数据，不会假装知道几点开始下雨。两家都失败时明确说明，正常聊天仍可继续。

白名单群里可用 QQ 的 @ 功能选中AI伙伴，再说“清远今天天气怎么样”。天气查询结果和失败提示都回复发起查询的会话，管理员在群里查天气也直接回原群，不另发私聊或“详情已私聊”回执。普通群友需明确城市；管理员设置天气城市/天气关心等管理指令仍保留群内短回执、详情私聊。

天气主动关心面向管理员私聊：明天最高温比今天低至少5℃，或出门前后一小时有降水预报时，可关心一次。默认出门时段08/18点。高德只有日预报时只说明明天有雨、时段未知。每天最多一次，07~22点间且服从配置的安静时段；沿用发送额度、全局暂停、静默、主动开关、3天无来信暂停、免打扰、专注、繁忙和40分钟主动冷却。新设置城市之前不会推送天气。

环境配置：

- `HEFENG_WEATHER_API_KEY`：和风API Key。
- `HEFENG_WEATHER_API_HOST`：控制台分配的专属 `*.qweatherapi.com`，也兼容 `QWEATHER_API_HOST` 或配置 `lifeServices.hefengHost`。不使用旧公共域名。
- `GAODE_WEB_API_KEY`：高德Web服务Key（天气、地理编码、POI搜索权限）。

Key放服务器服务环境，不放聊天、日志、源码、示例配置。Windows系统环境变更不等于正在运行的进程/远程服务器自动继承；部署时定向注入。和风Host缺失时明确用高德兜底。真实只读接口烟测：`node scripts/probe-life-services.mjs`（杭州为固定测试城市，不会改变用户默认城市，也不发QQ）。

## 共同回忆册

引用原消息，说“记住这一刻，第一次跑通项目”，或发 `[记住这一刻][我的备注]`。

```
[回忆][这个月]
[回忆][关键词][2]
[回忆详情][m_实际ID]
[更正回忆][m_实际ID][更正说明]
[回忆备注][m_实际ID][新备注]
[删除回忆][m_实际ID][确认]
```

每页10条、最多200条。保存原会话、原消息ID、作者、原消息时间（无法取得则标未知）、原文和备注。更正单独标注，保留引用原文；删除需确认。管理员私聊上下文可带最近3条已保存回忆；群里不会注入私人回忆，也不自动扫描全部聊天生成回忆。

## 纪念日

```
[纪念日][生日][每年10-31][提前1天][语音]
[纪念日][中秋][每年农历8月15日]
[纪念日][项目上线][2026-11-01]
[纪念日列表]
[删除纪念日][a_实际ID][确认]
```

当天北京时间09:00祝福，选填提前0~30天提醒和短语音。只填月日默认每年；带年份默认单次；公历2月29日等到下一次真实闰日，不挪到2月28日。农历依据Node/ICU中国历计算，闰月须显式写“农历闰4月1日”，搜索未来20年仍无有效日则拒绝。最多100条。

祝福只使用名称、实际日期及已保存回忆；复用现有DeepSeek提供方/模型/思考档位，一次无工具文本请求，费用计入 `internal:陪伴文案`，不自动换模型。失败用真实日期构造文字。语音复用当前音色和语音额度，失败保留已送达文字。暂停/静默或额度阻断会延后投递。

## 专注陪伴

```
陪我写代码半小时
[陪我专注][30分钟][写代码]
[延长专注][15分钟]
[专注状态]
[结束专注]
```

1分钟~12小时，结束后询问进展；可继续延长。仅暂停管理员私聊的普通自动问候、饭点和天气，不影响正常来信、原提醒任务、胶囊或纪念日；不覆盖旧免打扰，到期不会误解除旧设置。可重启恢复，过期只补一次询问。

## 时光胶囊

```
[时光胶囊][一个月后][希望未来的我已经把项目做好][附言]
[时光胶囊][明天9点][给未来自己的原话]
[胶囊列表]
[取消胶囊][c_实际ID][确认]
```

到期私聊送回原文、封存日期和选填附言。附言在创建时生成并保存，到期不改写。“一个月后”按日历月计算，月底落到目标月最后一天。最长5年、最多100个。提醒/胶囊不使用原来的任务文件，取消不会影响既有任务。

## 附近店铺和定位

```
[位置][杭州东站]
[附近][咖啡店]
[附近][杭州东站][咖啡店][杭州]
[找店][杭州][咖啡店]
[发定位][高德查询返回的地点ID]
[清除位置]
```

也可以@AI伙伴说“杭州东站附近有什么咖啡店”。位置不清楚时先询问；同名地点多个候选时要求补充，不擅自选第一个。用户自己分享的原生QQ定位可临时用于后续附近查询；模型也可使用同一发言人最近15分钟明确说出的地点。不同群、群成员、私聊的位置相互隔离，不从管理员的私聊城市猜群友位置。

临时位置30分钟过期、不落盘；地点结果10分钟过期，发定位只能选同一会话同一发言人的最新搜索结果。默认周边2000米、最多5家，查询清单显示地址、直线距离和发定位命令，不编造评分/营业状态/步行路线。请求发定位时发送QQ位置卡片；发送失败明确说明未确认送达，不自动改发长链接。卡片在具体QQ客户端的显示和点击结果须实际核对，多个地点逐个查询后发送。

2026-10-23更新：地点默认高德→腾讯地图→天地图→百度地图互相兜底；清单显示 `[发定位][实际ID]`。可发 `[找店][广州][广州塔][来源:腾讯地图]` 或 `[位置][韶关学院][韶关][来源:百度地图]`；指定来源表示优先，额度耗尽、权限/网络失败或无匹配时自动换其他可用地图，并说明实际来源，不再询问是否换源。四家都统一发送QQ位置卡片；天地图做显示坐标转换，百度直接请求GCJ-02坐标。各供应商权限与额度取决于使用者自己的账号，可通过其他健康来源继续定位；详见[地图发送边界](REQUEST-CONTINUITY.md)。

## 数据和运行

地点查询后5分钟内，同一会话本人可继续说“换腾讯的”“选第二个”“发这个”“还是刚才那个”。普通查询选择候选后仍不自动发送卡片；明确要求发送后才提交。天气/地图候选以最近一轮查询为准，忙时可排队处理；容量、时效及结果说明见[连续追问与请求收尾](REQUEST-CONTINUITY.md)。

`state/companion.json` 保存个人配置、回忆、纪念日、专注、胶囊和投递记录；写前备份、原子保存、损坏拒绝覆盖，已加入每日备份。通知发送成功才记完成，失败退避重试；QQ发送与本地写盘不是跨系统事务，发送后立即断电等极端情形可能重复，不宣称严格一次送达。

`companion.enabled=false` 关闭新入口和调度；`socialV2.tools.lifeServices=false` 关闭模型天气/地点工具。完整相关测试 `npm run test:companion`；回归 `npm run test:owner-tools-suite`。自动测试只用模拟QQ，真实QQ入站与原生定位呈现须由用户实际验收。
