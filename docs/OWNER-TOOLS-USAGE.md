# QQ 便捷指令使用说明

主要在**管理员 QQ 私聊AI伙伴**使用。群里发明确的方括号指令也会处理；群里只回简短回执，具体结果私聊管理员。非管理员不能执行这些管理指令。

总览：`[便捷帮助]`；分页帮助：`[指令 便捷]` 或 `[指令 13]`。名字/正文有空格时，每个参数单独一个方括号。

## 1. 引用消息快捷操作

- 在消息所在的会话引用它，发送 `[回应 👍]` / `[取消回应 👍]`。
- 撤回：引用后发送 `[撤回此条 确认]`。仍受 QQ 本身撤回时限/权限约束。
- 引用文本设个人提醒：`[提醒我 30分钟后]`；届时直接私聊管理员，不调用聊天模型。
- 私聊操作群消息：先 `[搜消息][小群][关键词]` 拿到原消息 ID，再 `[回应][小群][-123456789][👍]` 或 `[撤回此条][小群][-123456789][确认]`。
- 引用的转发副本不等于原群消息；跨会话操作必须指定原目标和原消息 ID，归属不符会拒绝。
- 表情支持 `👍` / `❤️` / `😂`，也可填 QQ 表情数字 ID。

## 2. 定时任务编辑

先 `[定时任务][查看所有]`，复制任务的完整 `r_...` ID。编辑不使用可能变化的序号。

```text
[任务改期][r_实际ID][明天9点]
[任务内容][r_实际ID][新的任务内容]
[暂停任务][r_实际ID]
[恢复任务][r_实际ID]
[任务顺延][r_实际ID][30分钟]
```

改成具体日期、顺延都只改变当前一期，后续继续原周期；明确改为 `[每天9点]` / `[每周五晚上8点]` 才改变重复规则。暂停不消耗次数；恢复过期任务会保留暂停时的剩余等待时间，不连环补发。原剩余次数/截止日期保留，超出截止会拒绝操作。

个人提醒也能用上述指令管理：`[提醒我][明天9点][记得交报告]`。普通定时任务依然由 AI 到点执行，个人提醒则直接发原文。

## 3. 临时免打扰

```text
[免打扰][示例好友甲][2小时]
[取消免打扰][示例好友甲]
```

最长30天，到期自动解除。只暂停自动主动问候和饭点开口，正常来信回复、个人提醒、明确任务和约定跟进照常。取消免打扰不会覆盖原来的“关闭主动”设置。管理员手动唤醒可绕过免打扰；会话繁忙时明确报错，请稍后重发，避免丢失手动意图。

## 4. 会话诊断

`[诊断][小群]` / `[诊断][示例好友甲]` / 群内 `[诊断][本群]`。

显示模式/白名单是否允许、DSH是否就绪、全局/会话主动开关、静默/免打扰、最后来信、未读、在途繁忙、发送限额、有限睡眠唤醒和近期错误样本。诊断不会新建聊天会话，不显示会话令牌。随机主动检查不保证每次都开口。

## 5. 目标别名

```text
[别名设置][小群][测试 群聊]
[别名列表]
[主动状态][小群]
[群信息][小群]
[别名删除][小群][确认]
```

别名绑定实际群/私聊号码，昵称变化不影响绑定；已有别名更换目标须末尾加 `[确认]`。最多100个，不能用纯数字、保留名或指令名；不会授予白名单外目标权限。需要消除数字歧义时，可显式写 `group:群号` / `private:QQ号`。

## 6. 私人便签/待办

```text
[记一下][周五交报告]
[待办]
[待办][2]
[待办][全部]
[完成待办][n_实际ID]
[恢复待办][n_实际ID]
[删除待办][n_实际ID][确认]
```

内容最多500字符，最多500条，每页20条。按管理员隔离并落盘，不依赖人格记忆；群内发指令时，内容和列表也只回管理员私聊。

## 7. 消息搜索/群摘要

```text
[搜消息][小群][开会][最近100条]
[群摘要][小群][最近100条]
```

范围10~200条，默认100条。结果注明接口实际返回数、时间范围和消息ID；每条文字最多1200字符。摘要最多使用最近24000字符的记录，并说明实际纳入条数；不会冒充全历史检索。摘要同一时刻只跑一个，间隔至少30秒。

搜索不调用模型。摘要沿用机器人当前配置的 DeepSeek 官方模型/思考档位和已有 key，一次文本请求、不带工具；用量记为 `internal:群摘要`。缺 key、供应商/模型/档位不在已验证范围、接口失败或输出不完整时明确报错，不自动换型、不自动重试。

## 8. 记忆纠正/主动话题偏好

```text
[更正记忆][示例好友甲][喜欢蓝色][喜欢绿色]
[更正记忆][示例好友甲][喜欢蓝色][喜欢绿色][确认]
[少聊话题][示例好友甲][宠物]
[话题偏好][示例好友甲]
[恢复话题][示例好友甲][宠物]
```

更正要求唯一匹配，先预览，再在5分钟内确认；记忆变化则重新预览。写入前备份状态与向量，移除旧向量后建立新索引；索引失败时如实报告结构化记忆已改、向量尚未同步。

每个会话最多10个少聊话题，每个最多20字。它影响主动开口方向和提示，对方主动聊到仍能正常回应；不会删除聊天记录或普通长期记忆。

## 持久化与备份

别名/待办：`state/owner-tools.json`；免打扰/偏好：`state/social-v2.json`；任务：`state/reminders.json`。新增文件已加入服务器备份可选清单。新工具写入前备份，备份/写盘失败明确报错；恢复密钥依旧需要另存离线。
