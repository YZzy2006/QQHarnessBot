# 2026-11-08 · 视频体验与轻量工作台源码发布

本次将后续功能以脱敏源码形式收录到公开机器人仓库，并将配套工作台分仓。原有公开Git历史保留，不上传维护者运行仓库的Git历史、真实配置、人物卡、state、聊天、日记、登录态、数据库/OSS配置或备份。

## 收录内容

- B站只读登录、视频采样/字幕及时间点追问、普通QQ标题/封面/链接分享与人物感想。
- 视频资料最长72小时，过期不因浏览工作台而自动重新分析；最小已读索引避免重复收费。
- 更明确的来信视频处理中/完成状态、视频追问意图、狗头/doge保命与傲娇的独立语义。
- 工作台的活动、日记/周记、人设与模型、视频偏好、记忆任务、反馈与结构化指令入口。
- 登录、Origin/CSRF、会话范围、操作版本与幂等、分页筛选、滚动保持和服务器只读状态。
- 面向开发者和AI的两份部署手册、配置地图、安全账号初始化、网关与Nginx示例。

## 公开版的独立配置

默认本地scrypt账号。可选MySQL只接受回环独立配置和兼容用户表，应用只读查询；可选头像OSS改为部署者自备的独立受保护JSON，不读取维护者博客/数据库。线上原有私人集成没有因此被修改。所有示例使用占位域名、占位账号或合成测试数据。

## 验证边界

- 从干净的独立克隆中安装依赖，检查本地相对导入与源码语法、文档链接、锁文件、发布白名单、敏感字段和维护者部署指纹。
- 工作台专题最终51项、视频专题19项通过；表情与预设针对性验证通过。新增独立配置测试拒绝宽松文件权限、符号链接、非法库名和远程数据库，并验证OSS不读取其他应用数据库。
- 网关/发布检查有独立测试。基础回归最终50/50业务组通过，随后14项预设/注册/发布门禁检查通过；GitHub CI结果另行观察，不用早期修复前失败记录冒充最终通过。
- 本地环境无FFmpeg时，2个真实抽帧用例会明确跳过；无网络纯逻辑用例仍执行，CI安装FFmpeg后执行真实抽帧。缺少可执行文件不是视频功能已验收。
- 依赖审计检查生产依赖高危问题；这不等于证明不存在所有安全缺陷。没有用维护者真实QQ/数据库/OSS/模型来跑公开版验收，没有重启线上服务。


首次GitHub干净Linux运行发现媒体安全清理辅助脚本漏入清单、服务器缺中文字体两项环境问题，已补齐脚本并将CI媒体/字体依赖显式安装；没有删除相关用例或用假结果代替实际FFmpeg/PNG验证。发布测试中的联系人/群号已统一替换为合成数据，不携带原运行环境测试号码。

离线预设安装幂等性回归使用临时项目、临时DSH_HOME和本地YAML依赖，不要求CI机器安装维护者的全局DSH，也不修改真实profile。

会话页与视频页共用主动视频开关，支持独立每日限额、0暂停、恢复默认和今日用量展示；修改不重置账本，在途任务重新校验授权。新增真实HTTP、状态持久化和额度隔离回归。

视频页改为筛选后单会话设置；档案新增可搜索分页的好友／群聊目录和白名单状态。旧会话条目可在关系重新核验后移出管理列表，保留记忆与访问保护。
