# AI伙伴扩展功能使用说明

入口：[扩展帮助]。白名单群的公开查询回复本群；管理员私人资料和周记只私聊。订阅默认关闭，以下时间均为北京时间。删除、发布和截图待办保存必须使用实际返回的完整ID及确认。

## 1. 群友个人设置

- [我的城市][广东省广州市天河区]：验证真实天气后保存本人的城市。
- [我的设置] / [查询偏好][简洁] / [查询偏好][详细]。
- [我的安静时段][22-8]：只管本人新扩展订阅通知，不覆盖旧免打扰。
- [我的城市][清除][确认]：仅清除本人的新默认城市。
- 群友可使用自己的城市查[天气][明天]；管理员没有个人城市时沿用旧陪伴城市，其他成员不借用管理员城市。

## 2. 天气连续查询

先发[天气查询][广州]，随后可说“那明天呢”“换成韶关”。遇到候选地区时说“选第二个”，也可照发完整候选指令。只记当前会话和本人的查询，5分钟过期，其他成员不能接走候选。自然语言首次提问在群里请@AI伙伴，方括号指令不必@。

## 3. 群知识

引用本群一条原消息，发[群知识投稿][项目启动方法]。默认待审核；机器人管理员在同群发[群知识待审]，再[群知识审核][k_实际ID][通过]或[拒绝]。

查询：[群知识][启动] / [群知识详情][k_实际ID]。只展示本群已审核资料，附原群/消息ID；管理员用[群知识过期][k_实际ID]停用旧资料。作者或管理员可[删除群知识][k_实际ID][确认]。

## 5. 今日安排

仅管理员：[今日安排]，合并本人天气、已有未完成便签/截图待办、今日原提醒任务和纪念日；原任务只读、不改期不迁移。群内请求只发短回执，安排详情私聊。

[今日安排订阅][08:00] / [今日安排订阅][关闭]。每天最多一期，不补发过去多天。

## 7. 管理员私有周记

[本周回忆]。只使用本周明确存入回忆册的片段和有时间依据的已完成待办；无素材如实说明，不编造经历。生成期间来源若变化会拒绝发送旧快照。

[周记订阅][周日20:00] / [周记订阅][关闭]。普通群友不能请求或订阅。群内发起仍只私聊管理员。

周记结果不写入聊天近期消息、未读、DSH聊天上下文或长期/向量记忆，不保存生成正文。发送分片带隔离标记，引用/模型消息详情/记忆写入阻止其正文回流；独立保留消息ID和内容哈希用于隔离，属于隔离记录，不是聊天记忆。图片重拍、手动改写或第三方重新转述无法可靠还原为同一原文；不把该限制说成任何情形都能识别。

## 9. 截图待办

引用一张清晰截图，发[截图待办]。机器人列出事项和识别的截止时间，**先逐条核对文字与时间**，再发[确认截图待办][p_实际ID][确认]。不确认不保存，预览10分钟过期；看不清/时间未知不会猜日期。

[我的待办] / [完成截图待办][t_实际ID] / [删除截图待办][t_实际ID][确认]。只有明确未来时间才设置到期私聊提醒；私聊必须已在白名单。截图待办独立于原提醒任务。

## 10. 文件版本对比

引用旧文件：[文件暂存][旧版]；引用新文件：[文件暂存][新版]；然后[文件对比][旧版][新版]。

支持现有文件读取器可提取正文的文本/PDF/DOCX/表格等；不读取用户给的本机路径。暂存只对当前会话的本人有效，15分钟过期、不落盘；清除用[清除文件暂存][确认]。

逐行比较文本，最多每版20000字符/600行、展示40项差异。超过范围明确标截断；不冒充全文或版式比较。图片型扫描PDF无可读文字时需先OCR。

## 16. 私人报错档案

管理员：[记录报错][标题][现象][原因][解决办法][环境（可选）]。

[查报错][关键词] / [报错详情][e_实际ID] / [报错验证][e_实际ID][已解决或待验证] / [删除报错][e_实际ID][确认]。默认待验证，不自动把猜测当成已解决；结果只私聊管理员，不混入聊天记忆。

## 18. 公告草稿与发布

管理员：[生成公告][本次实际改动]，或引用改动说明后发[生成公告]。先生成草稿并私聊预览，不自动发布。

[公告预览][a_实际ID]。群里生成的草稿绑定该群，[发布公告][a_实际ID][确认]；私聊生成的草稿需明确群目标：[发布公告][a_实际ID][group:真实群号][确认]。仅允许白名单群；已发布不重复，正在发送不能同时删除。

[删除公告][a_实际ID][确认]。模型文案须由管理员核对事实后再确认发布。

## 26. 共享歌单和片单

[推荐歌曲][歌名][公开链接][推荐理由] / [推荐电影][片名][公开链接][推荐理由]，理由可省略。

[歌单][关键词（可选）] / [片单][关键词（可选）] / [抽一首歌] / [抽一部电影] / [评价推荐][s_实际ID][评价]。

每人对同条投稿一条可更新评价，不覆盖他人；作者或管理员可[删除推荐][s_实际ID][确认]。列表按会话隔离；标题、理由、评价来自投稿人，未核验平台评分或播放可用性，不自动下载或播放。

## 30. 有来源的兴趣简报

[兴趣主题][Java,AI,游戏]，最多5项、每项20字；[兴趣简报]使用本人主题，也可[兴趣简报][Java]临时查询。

每次最多5条，提供来源链接、检索服务和原始发布时间；有日期的只取近7天，时间未知标明“未提供发布时间”，不将抓取时间充当发布时间。搜索结果不等于独立核实的新闻；无结果/服务失败不编造。

检索顺序为博查→DeepSeek Search→元宝搜索；前两家失败或没有可用结果时才请求元宝。不改变聊天模型，沿用用户提供的YUANBAO_SEARCH_API_KEY，密钥不会出现在简报中。

[简报订阅][08:30] / [简报订阅][关闭]，仅发本人白名单私聊，默认关闭。复用已配置的博查/DeepSeek检索主备，不切换聊天模型；不读取群知识或私人回忆作为公开搜索词。

## 通知、存储和验证

已识别扩展请求忙时按本人、本会话排队，最多4条等待；队列满会明确拒绝本条。轮到时等待超过2分钟则不执行并说明，前一条失败不阻塞后面的请求。天气短追问也可排队；普通聊天仍走原流程。这是当前进程内队列，不承诺重启后恢复。详见[连续追问与请求收尾](REQUEST-CONTINUITY.md)。

所有新通知受模式/白名单、全局暂停、静默、本人安静时段、临时免打扰、专注/繁忙、发送额度约束。发送失败退避重试，关闭订阅会抑制尚在检索/生成的结果。QQ发送和本地写盘不是跨系统事务，极端宕机仍可能重复。

新资料独立保存，写前备份、原子写入、损坏拒绝覆盖；纳入既有服务器备份。utilities.enabled=false可关闭新入口/调度，私有周记的隔离保护仍保留，不整份覆盖config.json。

测试：npm run test:utilities；相关回归：npm run test:owner-tools-suite。自动测试使用隔离QQ/模型/图片/文件桩，客户端实际呈现须由用户真实入站验收，不主动代发测试QQ。
